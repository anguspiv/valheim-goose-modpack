# Changelog

## 2.1.1 - 2026-11-13

- No gameplay change. Release now publishes to Thunderstore automatically from the GitHub release workflow.

## 2.1.0 - 2026-11-13

- Mod list: TeleportEverything removed (it pulled in TeleportBoats and QuickTeleport); TeleportCreatures and TeleportCarts added directly; Quick Stack Store Sort Trash Restock and PlantEasily added (client only).
- ValheimPlus 10.4.0 config moved to `org.bepinex.plugins.valheim_plus.cfg` with the agreed server settings: 2x gathering, pickables and drops; 2x station speeds with auto fuel and deposit; craft from chests at 50 m; bigger chests and carry weight; no structural integrity; brighter nights; bigger demister; faster breeding and eggs; 25% faster boats.
- PortalStations: teleport anything, personal device needs no fuel, anyone can rename stations.
- TeleportCreatures: only tames that follow you come through portals by default.
- Quick Stack: area stacking into nearby chests enabled. PlantEasily: replant on harvest.
- Installer: `--target` mode for the server image, YAML config support, removes the old `valheim_plus.cfg`.

## 2.0.0 - 2026-11-02

- Valheim 1.0 mod versions; Steam Deck installer.
